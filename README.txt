SOPHIE'S CONTENT STUDIO WEBSITE

This folder is a complete Vite + React website.

Easiest way to make it a real website:
1. Go to vercel.com and log in.
2. Click Add New Project.
3. Import this folder from GitHub, OR drag/upload this folder if using a compatible deploy tool.
4. Vercel will auto-detect Vite.
5. Click Deploy.

Easiest no-GitHub route:
1. Create a free GitHub account if needed.
2. Create a new repository called sophie-content-studio.
3. Upload all files in this folder.
4. Go to vercel.com > Add New Project > import the repository > Deploy.

How to edit stats after it is live:
Open the website > Update tab > edit the JSON > Save updated stats.
That saves the changes in your browser using localStorage.

Important:
The Update tab changes the data on your own device/browser. If you open the site from a different phone/computer, use Export Backup and paste/import the values manually, or ask ChatGPT to update the App.jsx defaults for a permanent site-wide update.

Files:
- src/App.jsx: the main Sophie Content Studio app
- src/main.jsx: React entry point
- index.html: website shell
- package.json: dependencies and scripts
